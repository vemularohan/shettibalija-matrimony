# Shettibalija Matrimony

## Outcome

Replace the placeholder with a trustworthy, culturally relevant matrimony service for Telugu-speaking Shettibalija families, prioritizing secure member registration, profiles, and discovery.

## Build

- Create the branded home page and connected public pages for search, membership information, about, contact, privacy, terms, and refund policy.
- Add Cloud email/password authentication and profile registration with validation, consent, and a multi-step progress flow; provide sign-in and session-aware profile access.
- Create the initial database schema and access rules for member profiles, preferences, photo metadata, shortlists, interests, contact requests, plans, memberships, payments, reports, and admin roles. Keep contact/family data private and only expose approved, safe profile fields to public search.
- Add approved-profile search and detail views, reporting/shortlisting actions, private photo upload/privacy controls, and a usable member area.
- Make membership options editable data rather than fixed business prices. Do not claim payment processing, SMS verification, or admin controls are operational unless configured and verified.
- Apply a responsive maroon, white, and restrained-gold visual system; add unique metadata to every content page.

## Sequence

1. Establish the visual system and homepage/navigation.
2. Apply Cloud schema, RLS, and private image storage.
3. Implement authentication, profile registration/editing, and member discovery.
4. Add policy/membership pages, responsive review, and validate the central flows.

## Limitations to surface

Live payment activation requires gateway credentials and webhook configuration. Pricing, contact details, and policy language that depend on the organization's decisions will be clearly marked for confirmation rather than invented.
